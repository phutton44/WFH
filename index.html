This app saves your data to PostgreSQL on Railway, via a small API you deploy. Once the API URL is in config.js, you can register and sign in with email and password.

  1. In Railway, add a PostgreSQL database, open Query (or connect with psql), and run postgres/schema.sql.
  2. Create a new empty service, connect the same repo, set Root Directory to server, and add env vars: DATABASE_URL (reference the Postgres plugin), JWT_SECRET (long random string), and CORS_ORIGIN (your site URL, e.g. GitHub Pages origin).
  3. Deploy, copy the service public HTTPS URL into config.js as WFH_API.baseUrl (see config.example.js).
  4. Reload this page.

Local dev: API may use http://localhost:3000; set the same origin in CORS_ORIGIN on the server.

Day types

  • Office

    Working day you marked as physically in the office.

  • WFH

    Working day you marked as working from home (explicit WFH only).

  • Leave

    Annual leave on this date; counts toward your yearly allowance.

  • Sickness

    Paid or unpaid sick leave; does not use annual leave; excluded from office/WFH tracked totals like leave.

  • Unassigned

    Monday–Friday working day with no office, WFH, leave, sickness, or NWD yet.

  • NWD

    Non-working day you marked on the calendar; excluded from office/WFH and leave totals like a weekend.

  • Bank hol.

    England & Wales public holiday on a weekday (non-working).

  • Weekend

    Saturday or Sunday (always non-working).
